# 📺 Smart TV Portal (Hisense Edition)

> **Autonomous Cloud-Based Smart TV Portal & IPTV Engine for Media Station X (MSX), VIDAA OS, and Lampa.**
> *0% computer reliance. Runs 24/7 directly from GitHub to your TV over Wi-Fi.*

---

## 🚀 How to setup on Hisense TV (VIDAA OS):

### 1. Install Media Station X
1. On your Hisense TV, open the **VIDAA App Store**.
2. Search for **Media Station X** (MSX) and install it.

### 2. Configure Start Parameter
1. Open **Media Station X** on your TV.
2. Go to: **Settings (Настройки)** ➔ **Start Parameter** ➔ **Setup**.
3. Enter your portal URL or short link:
   ```text
   https://raw.githubusercontent.com/vovamalina19742-ru/smart-tv-portal/main/msx.json
   ```
4. Click **OK** (Checkmark).

### 3. Enjoy!
* Full HD channels categorized by Federal, Movies, Sports, Discovery, Kids.
* Direct launch button for **Lampa** (online movies & series).
* 100% remote-friendly interface.
